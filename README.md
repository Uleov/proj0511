# Проект: Что приготовить из имеющихся продуктов (Тема 1)

Простая программа на Python для кухни. Она смотрит, какие продукты есть дома, сравнивает их с рецептами и показывает:
1. Какие блюда можно приготовить прямо сейчас (хватает всех продуктов).
2. Список всех блюд по порядку: от тех, где не хватает меньше всего, до самых сложных.
3. Список покупок для выбранного блюда (считает, сколько именно нужно докупить).

## Как запустить

Нужен только Python (версия 3). Дополнительно ничего устанавливать не надо.

```bash
python main.py
```

Программа прочитает файл `data.json`, покажет результат на экране и запишет его в файл `result.txt`.

Также можно передать другой файл и номер блюда:
```bash
python main.py data/deficit.json 1
```

## Как устроен входной файл (data.json)

Файл в формате JSON, в нем два блока:
- `stock` — сколько продуктов есть на кухне.
- `recipes` — список рецептов (название, id и сколько чего нужно).

Пример:
```json
{
  "stock": {
    "мука": 300,
    "яйца": 3,
    "молоко": 500
  },
  "recipes": [
    {
      "id": 1,
      "name": "Блины",
      "ingredients": {
        "мука": 500,
        "молоко": 500,
        "яйца": 2
      }
    },
    {
      "id": 2,
      "name": "Омлет",
      "ingredients": {
        "яйца": 2,
        "молоко": 100
      }
    }
  ]
}
```

## Что выдает программа

Пример вывода:
```text
Доступные блюда:
- Омлет (id 2)

Все рецепты:
Омлет (id 2): можно готовить
Блины (id 1): не хватает 1 продуктов

Список покупок для блюда Блины:
мука: докупить 200

Результат сохранен в файл result.txt
```

Если муки нужно 500 г, а дома есть 300 г, в список покупок пойдет 200 г, а не все 500.
