# Описание алгоритма

Алгоритм находится в функции `process_recipes`.

## Что делает алгоритм:
1. Берет каждый рецепт из списка.
2. Проверяет каждый нужный ингредиент:
   - Смотрит, сколько есть дома на складе (`stock`).
   - Если нужно больше, чем есть дома, считает разницу: `нехватка = нужно - есть`.
   - Записывает эту нехватку в список покупок для этого блюда.
3. Считает, скольких всего ингредиентов не хватило для блюда.
4. Сортирует все рецепты:
   - Сначала идут блюда, где нехватка 0 (их можно готовить прямо сейчас).
   - Потом те, где не хватает 1 продукта, 2 продуктов и так далее.
   - Если у двух блюд нехватка одинаковая, они сортируются по алфавиту названия.

## Пример на пальцах:
- Дома есть: мука 300 г, яйца 3 шт, молоко 500 мл.
- В рецепте «Блины» нужно: мука 500 г, молоко 500 мл, яйца 2 шт.
  - Мука: нужно 500, есть 300. Не хватает $500 - 300 = 200$ г. Добавляем в покупки.
  - Молоко: нужно 500, есть 500. Всего хватает.
  - Яйца: нужно 2, есть 3. Хватает с запасом.
- Итог для «Блинов»: не хватает 1 продукта (мука 200 г).
